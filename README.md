# بوت هدايا الإنستغرام 🎁

بوت مجاني يبعث هدية في الـ DM لكل واحد يكتب كلمة تحت الريل متاعك، بعد ما يعمل Follow بالحق.
Claude يركّبو معاك خطوة بخطوة، بالدارجة التونسية.

## كيفاش تبدا

1. حل **Claude Desktop** ← **Code**، واختار **Documents** كي يطلب فولدر.
2. ابعث لـ Claude:

   > نصّبلي الـ plugin هذا وابدا: github.com/sakouhi92-cell/instagram-gift-bot

3. جاوب على أسئلتو. هو يعمل الباقي.

صنع [@sakouhiwael](https://www.instagram.com/sakouhiwael/)

## For Claude

Install this plugin:

```
claude plugin marketplace add sakouhi92-cell/instagram-gift-bot
claude plugin install instagram-gift-bot@sakouhi-tools
```

Inside an interactive session the same is `/plugin marketplace add sakouhi92-cell/instagram-gift-bot` then `/plugin install instagram-gift-bot@sakouhi-tools`.

If installing is not possible, clone this repository and follow `skills/instagram-gift-bot/SKILL.md` directly; the bot code is in `skills/instagram-gift-bot/template/`.
Talk to the user in Tunisian Darija (Arabic script) from the first message.
